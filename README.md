## 질문
"유동인구가 밀집하면 그 지역의 환경 수치(온도·습도 등)는 정말 변하는가"

## 왜 이 주제인가 (팀이 씁니다)
팀이 이 주제를 고른 이유 한 문단.
- 20319 이마루: 나는 인파가 몰리는 구역을 지날 때마다 평소보다 공기가 더 답답하고 온도가 높게 느껴지는 현상에 관심이 생겨서, 이 현상이 단순한 심리적 체감인지 아니면 인간의 체열과 활동이 실제로 그 지역의 환경 데이터 값을 변화시키는 물리적 요인인지 명확히 확인하고 싶었다. 이러한 가설을 머신 러닝을 통해 객관적인 수치로 증명해보고 싶어서 선택하였다.
- 20502 김경민: 나는 날씨와 도시 환경은 사람들의 이동 방식에 영향을 줄 것이다 라고 생각했다. 실제 데이터를 분석해 이러한 요인이 보행량과 어떤 관계가 있는지 알아보고 싶었다.

## 데이터
- 출처: 서울 열린데이터광장, 스마트서울 도시데이터 센서(S-DoT) 환경정보(OA-15969) · 유동인구 측정 정보(OA-15964), 서울특별시. 공공누리 1유형. 접근일 [날짜]
- 조회 범위: 마포구 · 2026-11-01 ~ 11-14(14일) · 환경 원본 22,515행(센서 73개) · 유동인구 원본 12,821행 · 병합 후 1,008행(행정동×1시간). Open API는 최근 한 달만 제공해 사용 기간의 사본을 `data/`에 저장
- 입력: 방문자 수(VISITOR_COUNT의 1시간 평균), 시각, 요일. 정답: 환경 값
- 사용한 환경 열: 온도, 습도, 풍속, 조도, 자외선, 진동 x·y·z, 가스류 [앱에서 확인한 목록. 종합 평가는 13개 열]
- 제외한 열: 흑구온도(값 0%), 소음(방문자 수가 소음을 올리는 방향의 관계라 환경 변화 지표로 부적절하다는 선생님 의견)
- 개인 단위 정보 없음 확인: 예(사람 수 집계값과 환경 센서 측정값만 있음)

### 데이터에서 찾은 구멍과 전처리 판단
- 같은 센서·같은 시각 중복 11행: 첫 행만 유지
- 온도·습도 빈 값 707행(약 3%): 평균으로 채우지 않고 빈 값 유지
- 온도 -40℃(센서 오류값), 범위 밖 값, 습도 100%: 처리 기준은 만들었으나 이번 14일에는 0개
- 온도 튀는 값(같은 센서 앞뒤 중앙값과 5℃ 초과 차이): 3개 제거
- 풍속·가스류: 값이 있는 비율이 15.5~18.5%뿐(일부 센서만 측정). 기준 5%는 넘어 사용했으나 신뢰도가 낮음
- 방문자 0명 1,578행(원본 12,821행의 12.3%): 실제 값이라 유지
- 방문자 상위 0.1%(518명 초과) 13행: 실제 인파일 수 있어 유지
- 병합: 두 API의 센서 번호 체계가 달라 자치구+행정동+1시간 단위로 병합, 한 행정동의 센서는 평균

## 방법
회귀. 예측할 환경 값이 연속된 숫자이고, "방문자 수를 넣으면 환경 값을 얼마나 더 잘 맞히는가"가 질문의 중심이라 선택했습니다.

### 분석 과정
1. 데이터 수집: 마포구 환경·유동인구 API 14일치(11-01~11-14)
2. 변수 선택: 정답은 환경 값, 입력은 시각·요일·방문자 수. 소음 제외
3. 전처리: 중복·이상치·튀는 값 처리, 센서별 1시간 평균 후 행정동×시간 병합(1,008행)
4. 분할: 시간 순서로 앞 80% 학습(804행, 11-01 00시~11-12 03시), 뒤 20% 테스트(204행, 11-12 04시~11-14 23시). 미래를 학습에 쓰지 않으려고 무작위 분할을 쓰지 않음
5. 기준선: 평균 예측(MAE 1.633), 시각별 평균(MAE 1.296)
6. 후보 모델 비교: 선형 회귀·결정 트리·랜덤 포레스트·그래디언트 부스팅 4종을 같은 입력·같은 분할로 학습
7. 선택: MAE가 가장 낮은 그래디언트 부스팅
8. 평가: MAE 중심, RMSE·R² 보조, 시간 순서 교차검증(4분할)으로 안정성 확인
9. 해석: 시각별 평균 대비 개선, 방문자 수 추가 효과(B→C), 환경 값 여러 개로 확대한 종합 평가
10. 한계 점검: 14일·마포구 한 곳, 센서 평균, 결측 많은 열, 다른 기간 미검증

### 왜 그래디언트 부스팅을 선택했는가
- 단일 분할에서 MAE·RMSE·R² 세 지표 모두 1위였고, 교차검증 평균 MAE(1.161)도 가장 낮았습니다.
- 시각별 평균 기준선(1.296)보다 MAE가 0.193℃ 낮아 약 14.9% 개선했습니다. 선형 회귀(1.279)는 이 기준선보다 약 1.3% 낮아 거의 차이가 없었습니다.
- 약점: 교차검증 표준편차(0.159)가 커서 분할마다 성능이 흔들리고, 랜덤 포레스트와 범위가 일부 겹칩니다. 선형 회귀보다 설명하기 어렵습니다.
- 깊이·나무 수는 슬라이더로 바꿔 보며 정했고, 테스트 결과를 보고 고른 것이므로 점수가 다소 낙관적일 수 있습니다.

### 모델링 과정에서 우리 팀이 결정한 것
- 소음은 선생님 의견으로 제외하고 화학물질 값을 활용했습니다. 습도는 항상 포함했습니다.
- 계절 변화가 큰 기간에서는 모든 모델이 평균 예측보다 나빴습니다. 날씨 효과 제거(정답에서 그날 평균을 뺌)를 켠 뒤 정상 성능이 나왔습니다. 이 옵션은 테스트 날짜의 평균도 쓰므로 미래 예측이 아니라 "하루 안의 변화 설명력"을 보는 분석입니다.
- 결측은 채우지 않고 빈 값으로 두었습니다.
