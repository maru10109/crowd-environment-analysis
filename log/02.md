# 5차시 기록 — 스트림릿 앱 그래프 재현, 이슈 체크리스트 확인, 결측치 이상치 처리

## 20319 이마루
- 오늘 결정한 것: 스트림릿 앱 로딩 방식, 결측치 이상치 처리 방식 판단 기준을 세웠다.
- AI에게 보낸 프롬프트(원문):그래프와 발견 부분에서 그래프를 보여주는건 잘하고, 그래프 안의 값들을 보여주는것도 잘 되거든? 근대 그래프 부분 말고 데이터 개요, 결측치 이상치 처리 파트는 계속 똑같이 에러뜨네.. API 로딩은 바로 한번에 잘되던데 근데, 이거 최근 한달 데이터밖에 집계 못해? 과거 데이터도 쓰고싶은데.
- AI가 준 것 중 고치거나 버린 것과 그 이유: 이슈 체크리스트에서, 병합 방식을 센서 대응표로 사용하라고 적혀 있었는데, 저번에 정한 행정동, 시간으로 판단하는 방식을 계속 사용하기로 했다.
- 느낀 점: 오늘 깃허브 이슈 체크리스트를 좀 자세히 봤는데, 생각보다 도움되는 부분도 있었지만, 할루시네이션도 있는 부분이 있는것같아서 정확히 판단해야할 것 같다.
- AI 없이 내가 스스로 한 것: 스트림릿 앱 로딩이 오래걸려서, 스트림릿 앱 데이터 로드 방식을 전체 병렬로 만드는 판단을 스스로 해서, AI로 재현했다.
