# 7차시 기록 — 사용할 모델 정하기

## 20319 이마루
- 오늘 결정한 것: 여러 모델중에 어떤 모델을 사용해야할지, 그리고 모델 평가 기준을 어떻게 정할지 판단하고, 모델 분석을 앱을 통해 스스로 해보았다.
- AI에게 보낸 프롬프트(원문): 일단, 지금 우리가 해야하는건 이제 이 데이터를 가지고 어떤 방식으로 모델을 만들건지, 어떤 모델이 가장 효율적인건지에 대한 판단을 해서 적용해야해. 어떤 방식으로 모델을 만들까? 그리고 모델 방식을 정한 뒤에는 그 모델의 베이스라인의 기준점을 정하고, 모델평가지표를 활용해서 모델들의 성능을 비교하는 방법이 좋을것 같아. 너가 추천한 3가지 모델이 좋긴한데, 거기에 더해서 뭔가 전문적인 모델 하나만 더 추가 해서 앱을 만들어보라고 하시더라. 뭔가 좀 더 전문적인 모델이 하나 있으면 장점이 보일테니까,, 그럼 일단 새탭을 만들 코드를 전문을 줘
- 느낀 점: 모델 평가를 해보는 도중에, 데이터 기간을 온도 변화가 심했던, 계절 변화가 겹치던 날로 사용하니까 온도 회귀 모델의 평가지표가 이상하게 나와서, 어떤 기간을 사용해야 할지도 판단해야할것같다.
