# 9차시 기록 — 모델 평가에 활용할 평가지표 판단, 모델 이론 공부

## 20319 이마루
- 오늘 결정한 것: 평가지표를 MAE를 사용하기로 판단했다. 그래디언트 부스팅에 대한 이론을 배우고, 구술평가를 준비했다.
- AI에게 보낸 프롬프트(원문):나는 그래디언트 부스팅으로 설명하고 싶거든? 내 팀원이 선형회귀를 할거니까, 내가 다른 좀더 어려운거 하는게 좋을거같아. 그래서, 그래디언트 부스팅의 원리를 자세히 세세하게 설명해줄래? 그리고 왜 R제곱과 RMSE는 선택하지 않았는지도 알려줘. 하이퍼파라미터를 바꿨더니, 그래디언트 부스팅이 가장좋대. 일단 근데 그래디언트 부스팅을 왜 선택했는지, 그리고 학습 과정을 좀 더 일반적이게 설명해줘. 더 정확히 확실하게 설명해줘.
- AI가 준 것 중 고치거나 버린 것과 그 이유: AI가 가장 좋은 모델이 선형회귀라고 했지만, 하이퍼파라미터를 웹앱에서 직접 수정해서 어떤 모델이 더 좋은지 직접 스스로 판단해보았다.
- 느낀 점: 모델을 판단할때는 하이퍼파라미터가 가장 중요한 것 같다. 어떻게 지정하느냐에 따라서 성능이 달라지기 때문에..
- AI 없이 내가 스스로 한 것: 어떤 모델을 사용하여 판단할지, 스스로 생각해보았다.
